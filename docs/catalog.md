# 实验目录

启动命令中的 `case_id` 使用下表名称。每个实验均可在 rqt 和网页中运行。

## PID

| 实验 ID | 场景 | 改一次参数，观察什么 |
|---|---|---|
| `wheel_step` | 轮速阶跃 | 先把 Ki 和 Kd 设为 0。将 Kp 从 1 调到 3，比较最终轮速与目标的差距。再恢复 Ki = 3。 |
| `wheel_load` | 轮组持续负载 | 3 秒时增加阻力。分别用 Ki = 0 和 3 运行，观察轮速恢复到目标需要多久。 |
| `wheel_reverse` | 轮组正反转 | 1 秒加速，4 秒反转。加大 Ki，比较反转后首次过零时间和最低轮速。 |
| `wheel_ramp` | 斜坡速度指令 | 目标在 1 至 4 秒间匀速增加。把 Ki 从 0 调到 4，比较斜坡段误差和停升后的误差。 |
| `wheel_bump` | 越过阻力带 | 3 至 4 秒施加短促阻力。固定 Kp，提高 Ki，比较离开阻力带后的回弹。 |
| `wheel_limit` | 电机限幅与积分饱和 | 1 至 4 秒的目标为 2，驱动上限为 1。用 anti_windup = 0 和 1 对照，观察目标回落至 0.3 后的恢复时间。 |
| `wheel_noise` | 微分放大测速噪声 | 设 Kd = 0.08。将微分滤波时间从 0 调至 0.08 秒，同时查看 effort，观察控制抖动。 |
| `wheel_encoder` | 低分辨率编码器 | 目标为 0.35，编码器以 0.2 为一格。对照 measurement 与 output，观察 Ki 从 0 增至 4 后平均误差和周期摆动。 |

## LQR

| 实验 ID | 场景 | 改一次参数，观察什么 |
|---|---|---|
| `cart_stop` | 滑台定位 | 将 R 从 1 增至 5，比较施力峰值与到达 1 米位置的时间。 |
| `cart_heavy` | 重载滑台 | 滑台质量增至 3 kg。固定 R，将位置权重从 8 增至 24，观察施力是否触及 4 N。 |
| `cart_brake` | 滑台初速制动 | 滑台以 1.5 m/s 滑出，目标位置保持为零。将速度权重从 2 增至 12，比较最远滑出距离。 |
| `cart_push` | 小车短时受推 | 3 至 3.5 秒受 2 N 干扰。提高位置权重，观察峰值位移偏差和恢复时的施力。 |
| `cart_bias` | 小车恒定阻力 | 3 秒后增加 1 N 恒载。将位置权重从 8 增至 30，检查末段还有多少位置偏差。 |
| `cart_limit` | 低推力定位 | 驱动力限于 ±0.6 N。将 R 从 1 降到 0.1，观察控制量贴着上限的时间和越过目标的位置。 |
| `cart_waypoints` | 滑台双工位切换 | 1 秒去 0.8 米，4 秒返回原点。将速度权重从 2 增至 10，比较折返时的过冲和耗时。 |

## Kalman

| 实验 ID | 场景 | 改一次参数，观察什么 |
|---|---|---|
| `range_step` | 测距读数突变 | 2 秒时距离跳变。先把 R 从 0.0625 增至 0.3，观察估计抖动和跟随延迟。 |
| `range_wave` | 往复距离估计 | 固定 R，将 Q 从 0.002 增至 0.02，比较估计峰值与真实峰值出现的时间。 |
| `range_still` | 静止距离降噪 | 真值固定 0.8 米。减小 Q，比较最后 4 秒的估计与原始读数抖动。 |
| `range_noisy` | 测距噪声变大 | 传感器标准差为 0.6 米。对照 R = 0.0625 与 0.36，比较平稳段抖动和阶跃后的滞后。 |
| `range_pulse` | 短时台阶读数 | 目标在 3 至 3.4 秒升高 1 米。减小 Q，观察峰值被削弱多少。 |
| `range_cruise` | 匀速里程估计 | 以 0.6 m/s 匀速行驶。查看 velocity，多次尝试不同 R，比较估计速度接近真值所需时间。 |
| `range_dropout` | 里程观测中断 | 3 至 5 秒 valid 为 0，measurement 保持最后读数。观察 output 仅靠速度预测前进，以及读数恢复时的修正。 |
| `range_turn` | 小车折返估计 | 4 秒时速度从 +0.5 变为 −0.5 m/s。比较 q_accel = 1 和 40 时的转向滞后与匀速段抖动。 |

## 串级 PI

| 实验 ID | 场景 | 改一次参数，观察什么 |
|---|---|---|
| `carriage_loops` | 位置与速度串级调节 | 将 outer_kp 设为 1，先比较 inner_ki 为 0 和 4 时的两条速度曲线。固定内环后，把外环从 1 提到 8，再看位置过冲。 |
| `carriage_cap` | 限速往返滑台 | 外环限速 ±0.4 m/s；1 秒去 1 米，5 秒返回。提高 outer_kp，检查速度目标削顶的时段和最终位置。 |
